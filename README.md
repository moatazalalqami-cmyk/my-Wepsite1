# معتز العلقمي | المدونة الرسمية
مدونة فاخرة مطورة باستخدام Next.js 14, Tailwind CSS, PostgreSQL, و Prisma.
تدعم اللغتين مع تركيز على القراءة العربية (RTL) والوضع الليلي.
## التثبيت (Installation)
 1. npm install
 2. قم بإعداد قاعدة البيانات في ملف .env بناءً على .env.example
 3. npx prisma db push
 4. npm run seed لتوليد حساب المدير والمقالات التجريبية
 5. npm run dev
